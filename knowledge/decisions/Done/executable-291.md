> **(1) `grep` here is a ugrep shim, and any pattern beginning with `**` is a REGEX ERROR.** It prints an error to stderr and **NOTHING to stdout**; `grep -F` returns correctly. **Use `grep -F` for every literal in this plan.** This matters most for the ABSENCE checks: an errored grep produces empty stdout, which reads as "not found → PASS" having verified nothing. `/usr/bin/grep` fails the same way; `-F` is the fix, not a different binary. > - `ls -t <no-match-glob> 2>/dev/null || true` → **still prints `zsh: no matches found`**. The error is raised by the SHELL at expansion time, so the command never runs: `2>/dev/null` does not suppress it (it is not the command's stderr) and `|| true` never fires (there is no command to fail).
